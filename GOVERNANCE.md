# Governance

## Project scope

Image Prompt Atlas maintains original, structured AI image prompt cases, production templates, generated previews, a searchable website, and agent-ready data. Changes should improve findability, reuse, validation, or production readiness.

## Roles

- Contributors propose issues, content, code, documentation, and reviews.
- Maintainers triage reports, review pull requests, protect project quality, manage releases, and enforce community policies.
- A contributor becomes a maintainer through sustained, high-quality participation and explicit approval from existing maintainers.

## Decisions

Routine changes are accepted through maintainer review. Taxonomy removals, schema-breaking changes, content-policy changes, and major architecture decisions require a public issue describing motivation, migration impact, and alternatives before implementation.

Maintainers prefer consensus. When consensus is not practical, the maintainer responsible for the affected area makes the final decision and records the rationale in the issue or pull request.

## Releases

The project follows semantic versioning where practical. Breaking schema or automation changes require a major version, additive features require a minor version, and corrections use a patch version. Significant user-visible changes belong in `CHANGELOG.md`.

## Conflicts of interest

Reviewers should disclose material relationships that could affect a decision and step away when impartial review is not possible.
